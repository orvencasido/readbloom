# ReadBloom

An interactive literacy learning, assessment, and reading tracking platform powered by AI.

## Repository Structure

- **`student_readbloom/`**: Flutter application for students with interactive reading materials, voice recognition, and assessment features.
- **`teacher_readbloom/`**: Flutter web application for teachers to manage reading modules, monitor student progress, and grade performance.
- **`admin_readbloom/`**: Flutter web application for administrators to manage schools, curricula, accounts, and system analytics.
- **`supabase/`**: Supabase backend migrations, schema definitions, seed data, and Edge Functions.
